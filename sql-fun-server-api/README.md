# `sql-fun-server-api`

Shared JSON-RPC protocol and API type definitions used by
[`sql-fun-client`](https://crates.io/crates/sql-fun-client) and
[`sql-fun-server`](https://crates.io/crates/sql-fun-server). Applications using
the service normally connect through `sql-fun-client`.

See the [Rust API documentation](https://docs.rs/sql-fun-server-api) for the
types and the [Server API Reference](https://kazuk.github.io/sql-fun/api/server-api.html)
for the protocol.
