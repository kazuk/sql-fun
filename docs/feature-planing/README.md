# Feature Planning Documents

This directory contains feature planning documents for `sql-fun`.  
Each file represents an idea that is not yet implemented — and may or may not be developed in the future.

These documents are shared to encourage experimentation and collaboration.  
No timelines. No obligations. Just ideas — open for anyone to explore.

## Contribution Policy

If any of these ideas interest you, you're welcome to explore or contribute in whatever way works best for you:

- 💡 Preferably, start by opening a Pull Request or issue to propose implementing the feature in `sql-fun` itself.
- 🛠️ Alternatively, you're absolutely welcome to build it as a separate tool or library in your own repository.
  - You don't need permission.
  - You can work at your own pace and in your own style.
    - We understand that not everyone prefers to collaborate directly in a shared repository.
- 🔗 If you do build something externally, feel free to send us a PR linking your work in the README or docs.
- 💬 Even leaving a comment or emoji reaction is a meaningful way to show interest!

We believe good ideas should grow — however and wherever they take root.
