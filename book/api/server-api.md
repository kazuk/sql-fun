# Server API Reference

The server API lets a client analyze SQL against an explicitly selected schema
and read paged results over a persistent connection.

Start with [connection and authentication](initialize.md), then follow the
[schema context and query analysis workflow](check-analysis-design.md). The
[method reference](methods.md) describes request and result schemas. You can also
[use the API through `sql-fun api`](cli-api.md).
