# Common clauses

Find shared query scope, input constraints and result behavior here. Statement
pages describe where each clause is available and any statement-specific rules.

- [WITH](clauses/with.md): CTE scope and modifying bodies.
- [FROM](clauses/from.md): sources, joins, table functions and sampling.
- [WHERE](clauses/where.md): row predicates.
- [GROUP BY](clauses/group-by.md): grouping keys and GROUPING.
- [HAVING](clauses/having.md): group predicates.
- [WINDOW and OVER](clauses/window.md): named windows and frame expressions.
- [ORDER BY](clauses/order-by.md): output names, positions and compound scope.
- [LIMIT and OFFSET](clauses/limit-offset.md): row-count expressions.
- [RETURNING](clauses/returning.md): DML output columns.

See also [statements](statements.md),
[expressions and shared rules](expressions.md), and the
[SQL Analysis Reference](../sql-analysis.md).
