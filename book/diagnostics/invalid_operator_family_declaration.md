# invalid_operator_family_declaration

Code: `invalid_operator_family_declaration`. Severity: Error.

A PostgreSQL operator family or operator class declaration could not be
applied. Check the diagnostic message for the missing reference, duplicate
identity or member slot, or invalid membership change. The statement leaves
the existing catalog unchanged.

See [CREATE OPERATOR CLASS](../sql-analysis/statements/create-operator-class.md)
and [operator-family declarations](../sql-analysis/statements/operator-families.md).
