# `sql-fun-core`

Shared types and definitions for the SQL analysis environment used by
[`sql-fun-client`](https://crates.io/crates/sql-fun-client),
[`sql-fun-sqlast`](https://crates.io/crates/sql-fun-sqlast), and other
components. Applications integrating with these components may use its shared
types directly.

See the [Rust API documentation](https://docs.rs/sql-fun-core).
